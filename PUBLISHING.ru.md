# Публикация и очистка истории

[English](PUBLISHING.md) | [Русский](PUBLISHING.ru.md)

Локальные истории были очищены 2026-10-08 перед публикацией в новых репозиториях:

- Приложение: https://github.com/proxymades/client-executor-mobile
- Сервер: https://github.com/proxymades/client-executor-server

Прежние приватные репозитории GitHub остались без изменений. Force push в них не выполнялся. Локальные настройки базы, файлы Firebase и адреса сервисов приложения остаются на компьютере разработки и исключены из Git.

## Что удалено

- Из истории приложения: исходная конфигурация Firebase-проекта Android.
- Из истории сервера: `.env` и JSON сервисного аккаунта Firebase Admin.
- В историческом коде сервера: исходные секреты подписи JWT и изображений заменены чтением переменных окружения. Точные значения удалены из исторических файлов и сообщений коммитов.

Перезапись сохранила все 29 коммитов приложения и 27 коммитов сервера, существовавшие на момент очистки. Сравнение контрольных сумм подтвердило, что текущие отслеживаемые рабочие файлы не изменились. Все сохранённые blobs и объекты коммитов, включая недостижимые, были проверены на известные удалённые значения и дополнительные признаки приватных ключей и токенов; совпадений не осталось. Единственная локальная ветка сохранена и переименована в `main` для новых репозиториев.

## Проверки перед дальнейшими публикациями

```sh
npm run check:public
npm run check:public -- --history
```

Сканер выводит только пути файлов, без значений секретов. Режим проверки истории анализирует все достижимые файловые blobs. Это проверка конкретных признаков, а не полный аудит безопасности. Не сливайте старую неочищенную историю с другого компьютера или из прежних приватных репозиториев.

Очистка истории не отзывает учётные данные. Пароль базы и ключ Firebase Admin сохранены локально и не заменялись. Текущий API использует новый секрет подписи, сгенерированный при подготовке. Если какие-либо прежние учётные данные вышли за пределы приватного хранения, отзовите или замените их у соответствующего провайдера.

## Оставшиеся проверки

Совместимость нативной iOS-сборки с установленным Xcode ещё требует доработки. Настоящие скриншоты, доставка Firebase push и отдельный тест конкурентных операций MySQL пока не проверены; см. [README](README.ru.md) и [отчёт подготовки](docs/PREPARATION.ru.md).
